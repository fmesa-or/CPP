
-Program tajes a fille as an argument
-Each line in file uses the format:	"date | value"
-Valid date:	Year-Month-Day
-Valid value:	float or positive integer. [0 - 1000]

	->Must use at least one container to validate. Don't use it in the rest of module.
	->Should handle possible errors with an appropiate error message

	Example of an input.txt file:

	------------------------------
		$> head input.txt
		date | value
		2011-01-03 | 3
		2011-01-03 | 2
		2011-01-03 | 1
		2011-01-03 | 1.2
		2011-01-09 | 1
		2012-01-11 | -1
		2001-42-42
		2012-01-11 | 1
		2012-01-11 | 2147483648
		$>
	-------------------------------

	->When a date doesn't exist in the DB, use closest one with lower date.

	Use example:

	-----------------------------
		$> ./btc
		Error: could not open file.
		$> ./btc input.txt
		2011-01-03 => 3 = 0.9
		2011-01-03 => 2 = 0.6
		2011-01-03 => 1 = 0.3
		2011-01-03 => 1.2 = 0.36
		2011-01-09 => 1 = 0.32
		Error: not a positive number.
		Error: bad input => 2001-42-42
		2012-01-11 => 1 = 7.1
		Error: too large a number.
		$>
	-----------------------------
